- 六個樣本頁（/product-samples/koko-printable、/product-samples/noor-worksheet 及各自的 /zh、/ar 版本）不在 sitemap；它們的 robots meta 均為 noindex,follow，X-Robots-Tag 均為 noindex, nofollow。資料可確認 noindex 指令，無法單憑資料確認設定意圖；meta 與 header 的 follow 指令不同。
- /robots.txt 與 /sitemap.xml 也不在 sitemap；兩者是非 HTML 資源。
- 尚缺 Search Console、CrUX／真實使用者 Core Web Vitals，以及兩條路徑的 14 天事件基準；現有資料不足以推論搜尋表現或轉換趨勢。
